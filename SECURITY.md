# Security Policy

AgentOS v0.1 is a **local development prototype only**. It is not safe for public deployment. It has no user authentication and no isolation of multiple users' data.

To report a security issue, use GitHub's private vulnerability reporting mechanism if enabled, or contact maintainers privately. Do not open a public issue containing exploit details, secrets or personal data.

We do not currently promise a response SLA. Secure credential management, server-side authorization, secret redaction, sandbox boundaries and tenant isolation are release-blocking requirements for the hosted product.
